# LogicTask page

HOSTED AT:
https://logiikka-teht-v-t.vercel.app/

- The application uses an Express backend.
- React + Vite frontend
- Postgres database.

### In the application you can do exercises from the following areas of logic:
- Propositional logic
- Resolution method
- Semantic tree
- Natural deduction

(Note that different names are used for these methods in different places.)

### In short, the application is used by:
1. Logging in / registering on the server.
2. Opening one of the sections (introduction is a good one).
3. First reading the instructions for the upcoming exercises, and then moving on to the exercises.
4. Write (or enter in some other way) your answer to the exercise and submit it.
5. The exercise is evaluated on the server side.
6. Completed exercises are listed on the user page.
